## Приложения

### Приложение А. Глоссарий статусов заказа

Текущий статус заказа определяется **последней записью** в истории статусов.

| Код | Название | Описание |
|-----|----------|----------|
| NEW | Новый | Заказ создан, ожидает обработки менеджером |
| COOKING | Готовится | Заказ на кухне |
| DELIVERING | Доставляется | Заказ у курьера / в пути к клиенту |
| DELIVERED | Доставлен | Заказ вручён клиенту |
| CANCELLED | Отменён | Заказ отменён рестораном или по правилам отмены |

Переходы между статусами выполняют менеджер, администратор и курьер (в рамках своих прав) через интерфейс заказа.

### Приложение Б. Часто задаваемые вопросы (FAQ)

**Не могу войти в систему.**  
Проверьте логин, пароль и раскладку. Сотрудники — обратитесь к администратору для сброса пароля. Клиенты — уточните в ресторане.

**Клиент не видит блюда в меню.**  
Администратор/менеджер: проверьте, что меню **активно** и в него добавлены блюда.

**Заказ долго в статусе «Готовится».**  
Менеджер: уточните на кухне; при готовности смените статус и назначьте курьера.

**Курьер не получает заказы.**  
Включите **«На смене»**; менеджер должен **назначить** заказ именно этому курьеру.

**Хочу изменить адрес после оформления.**  
Клиент: свяжитесь с рестораном. Менеджер может изменить данные заказа в desktop-интерфейсе.

**Корзина опустела после обновления страницы.**  
Корзина хранится в браузере; очистка данных сайта удаляет корзину. Добавьте блюда снова.

**Кнопка «Оценить заказ» не работает.**  
Функция не реализована в текущей версии — см. раздел для клиента.

| Возможность | Admin | Manager | Courier | Client |
|-------------|:-----:|:-------:|:-------:|:------:|
| Управление меню и блюдами | + | + | | Просмотр |
| Управление ингредиентами | + | + | | |
| Управление менеджерами и курьерами | + | | | |
| Просмотр/редактирование заказов | + | + | Свои | Свои |
| Назначение курьера | + | + | | |
| Смена статуса доставки | + | + | + | Ограниченно |
| Рабочий статус курьера | + | + | + | |
| Регистрация и профиль клиента | | | | + |
| Адреса доставки | + | + | | + |
| Справочник ролей и статусов (полный) | + | | | |

«+» — доступно в полном объёме для роли; «Свои» — только заказы, назначенные или созданные пользователем; «Просмотр» — без редактирования каталога; «Ограниченно» — действия, разрешённые API для клиента (например, отмена на раннем этапе, если реализовано).
