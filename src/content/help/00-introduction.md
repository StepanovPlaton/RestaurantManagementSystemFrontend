# Руководство пользователя Food Rush

## Введение

**Food Rush** — веб-система управления рестораном с доставкой еды. Она объединяет работу персонала ресторана и заказы клиентов в едином приложении: сотрудники ведут меню, заказы и персонал, клиенты выбирают блюда и отслеживают доставку, курьеры выполняют доставку назначенных заказов.

Данное руководство предназначено для **всех ролей** системы. Оно разделено по типам пользователей, но доступно целиком каждому авторизованному пользователю — вы можете изучить возможности других ролей для общего понимания процессов.

### Для кого эта справка

| Роль | Интерфейс | Краткое назначение |
|------|-----------|-------------------|
| **Администратор** | Desktop (боковое меню) | Полное управление рестораном, персоналом и справочниками |
| **Менеджер** | Desktop | Заказы, клиенты, меню и блюда без управления сотрудниками |
| **Курьер** | Mobile | Доставка назначенных заказов, рабочая смена |
| **Клиент** | Mobile | Заказ еды с доставкой, профиль и адреса |

### Системные требования

- Современный браузер: Chrome, Firefox, Safari или Edge последних версий.
- Стабильное подключение к интернету.
- Для сотрудников рекомендуется экран от 1280 px по ширине; для клиента и курьера — смартфон или эмуляция мобильного вида в браузере.
- JavaScript должен быть включён; файлы cookie и локальное хранилище используются для сессии и корзины клиента.

### Как устроена навигация

**Desktop (администратор и менеджер):** слева постоянное боковое меню с группами «Ресторан», «Сотрудники» (только у администратора), внизу — «Настройки», «Справка» и «О разработчиках». Основная работа ведётся в таблицах и модальных окнах.

**Mobile (клиент и курьер):** внизу экрана панель с 2–4 разделами. Переход между разделами не сбрасывает сессию. Справка и сведения о разработчиках открываются из профиля (клиент, курьер) или из бокового меню (сотрудники desktop).

### Как пользоваться этой справкой

1. Откройте раздел **«Содержание»** (на телефоне — кнопка вверху страницы, на компьютере — колонка слева).
2. Выберите нужный подраздел — страница прокрутится к соответствующему заголовку.
3. Иллюстрации показывают прототипы экранов; фактический интерфейс может незначительно отличаться по деталям оформления, но логика действий сохранена.

### Условные обозначения

- **Кнопка** — элемент интерфейса, на который нужно нажать.
- **Модальное окно** — всплывающая форма поверх страницы.
- **Таблица** — список записей с действиями в строке или в меню «⋯».
